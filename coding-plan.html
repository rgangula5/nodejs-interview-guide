Coding Interview Plan (JavaScript)

A ~10-week, pattern-based roadmap from "I can write a for-loop" to "I can solve easy/medium in an interview." Do it in JavaScript. ~120 curated problems.

Contents 0 · The Rules (read this first) 1 · JavaScript Toolkit for Problems 2 · The 15 Patterns 3 · The 10-Week Plan 4 · Full Problem List by Pattern 5 · Readiness Check

0 · The Rules (this is 80% of success)

Practice WITHOUT AI. Use ChatGPT/AI to learn a pattern after you've struggled — never to write the first solution. If AI writes it, your brain doesn't build the recall the interview tests.
  • The 3-step method for every problem: (1) attempt cold for 20–30 min; (2) if stuck, read the solution & understand it fully; (3) re-solve it from memory the next day. Step 3 is where learning sticks.
  • Practice by pattern, not randomly. Do 5–8 problems of one pattern in a row so it clicks.
  • Talk out loud as you solve — interviewers score your thinking, not just the answer.
  • Always state time & space complexity (Big-O) at the end. Interviewers always ask.
  • Redo failures. Keep a list of problems you couldn't solve; revisit weekly.
  • Consistency > cramming. 1.5–2 hrs/day, 5–6 days/week beats a weekend binge.

Resource: neetcode.io/practice — free, has JS solutions + video explanations, and this plan mirrors its structure.

1 · JavaScript Toolkit for Problems

Since your coding is rusty, memorize these — they appear in nearly every problem.

// Arrays
arr.push/pop/shift/unshift, arr.slice(i,j) (copy), arr.splice (mutate)
arr.map / filter / reduce / find / some / every / includes / indexOf
arr.sort((a,b) => a-b)         // numeric ASC (default sort is lexical!)
new Array(n).fill(0)           // fixed-size array
[...arr]                       // copy;  Math.max(...arr)

// Strings (immutable!)
s.length, s[i], s.charCodeAt(i), String.fromCharCode(n)
s.split(''), s.slice, s.substring, s.toLowerCase, s.includes

// Map & Set (your best friends for O(1) lookup)
const m = new Map(); m.set(k,v); m.get(k); m.has(k); m.size; [...m]
const seen = new Set(); seen.add(x); seen.has(x); seen.delete(x)
const count = new Map();                       // frequency map
count.set(c, (count.get(c) || 0) + 1);

// Numbers
Math.max/min/abs/floor/ceil/round, Infinity, -Infinity
Number.MAX_SAFE_INTEGER

// Objects as hashmaps
const freq = {}; freq[key] = (freq[key] || 0) + 1;

// Queue/Stack: use an array (push/pop = stack; push/shift = queue - O(n) shift!)
// For big queues use two pointers or a real deque to avoid O(n) shift.
#1 JS gotcha in interviews: [3,1,20].sort() gives [1,20,3] (lexicographic). Always pass a comparator: .sort((a,b)=>a-b).

2 · The 15 Patterns (cover ~80% of questions)

  • Arrays & Hashing — frequency maps, sets for dedupe/lookup.
  • Two Pointers — sorted arrays, palindromes, pairs.
  • Sliding Window — subarray/substring with a condition.
  • Stack — matching, monotonic stack, parsing.
  • Binary Search — sorted data, "search the answer".
  • Linked List — pointers, fast/slow, reversal.
  • Trees (BFS/DFS) — traversal, recursion.
  • Tries — prefix problems (lighter weight).
  • Heap / Priority Queue — top-K, streaming median.
  • Backtracking — subsets, permutations, combinations.
  • Graphs — BFS/DFS, islands, topological sort.
  • 1-D Dynamic Programming — climbing stairs, house robber, coin change.
  • Greedy — local choice → global (Kadane, intervals).
  • Intervals — merge/overlap.
  • Math & Bits — number tricks (lightest priority).

3 · The 10-Week Plan ~1.5–2 hrs/day

Each week = one or two patterns, ~10–14 problems (mostly easy→medium). Do the 3-step method on each.

Week 1 — Arrays & Hashing

Two Sum · Valid Anagram · Contains Duplicate · Group Anagrams · Top K Frequent Elements · Product of Array Except Self · Valid Sudoku · Longest Consecutive Sequence

Goal: get fluent with Map/Set and frequency counting. This is the foundation.

Week 2 — Two Pointers + Sliding Window

Two Pointers: Valid Palindrome · Two Sum II (sorted) · 3Sum · Container With Most Water
Sliding Window: Best Time to Buy/Sell Stock · Longest Substring Without Repeating Characters · Longest Repeating Character Replacement · Permutation in String

Week 3 — Stack + Binary Search

Stack: Valid Parentheses · Min Stack · Evaluate Reverse Polish Notation · Daily Temperatures
Binary Search: Binary Search · Search a 2D Matrix · Koko Eating Bananas · Find Minimum in Rotated Sorted Array · Search in Rotated Sorted Array

Week 4 — Linked Lists

Reverse Linked List · Merge Two Sorted Lists · Linked List Cycle · Reorder List · Remove Nth Node From End · Add Two Numbers · Copy List With Random Pointer · LRU Cache (design — very common)

Week 5 — Trees (part 1: DFS/BFS basics)

Invert Binary Tree · Maximum Depth · Diameter of Binary Tree · Balanced Binary Tree · Same Tree · Subtree of Another Tree · Lowest Common Ancestor (BST) · Level Order Traversal (BFS)

Week 6 — Trees (part 2) + Heaps

Trees: Right Side View · Validate BST · Kth Smallest in BST · Construct Tree from Preorder/Inorder
Heaps: Kth Largest in a Stream · Last Stone Weight · K Closest Points to Origin · Kth Largest Element in Array · Task Scheduler

Week 7 — Backtracking

Subsets · Combination Sum · Permutations · Subsets II · Combination Sum II · Word Search · Palindrome Partitioning · Letter Combinations of a Phone Number

Week 8 — Graphs

Number of Islands · Clone Graph · Max Area of Island · Pacific Atlantic Water Flow · Surrounded Regions · Rotting Oranges · Course Schedule (topo sort) · Course Schedule II · Number of Connected Components · Graph Valid Tree

Week 9 — 1-D Dynamic Programming

Climbing Stairs · Min Cost Climbing Stairs · House Robber · House Robber II · Coin Change · Longest Palindromic Substring · Palindromic Substrings · Maximum Product Subarray · Word Break · Longest Increasing Subsequence

Week 10 — Greedy, Intervals, Math + MOCKS

Greedy: Maximum Subarray (Kadane) · Jump Game · Jump Game II · Gas Station · Partition Labels
Intervals: Insert Interval · Merge Intervals · Non-overlapping Intervals · Meeting Rooms · Meeting Rooms II
Math/Bits: Single Number · Number of 1 Bits · Missing Number · Reverse Integer
+ Do 3–4 timed mock interviews (45 min, 1–2 mediums, out loud).
Short on time? Do Weeks 1–5 + 8 + 9 (Arrays/Hashing, Two Pointers, Sliding Window, Stack, Binary Search, Linked List, Trees, Graphs, 1-D DP). That's the highest-frequency 70% of interview questions.

5 · Readiness Check

You're interview-ready for most companies when you can:

  • Solve a random medium in ~25–35 min, talking through it, without AI.
  • Recognize the pattern within the first couple minutes ("this is sliding window").
  • State time & space complexity confidently.
  • Redo any Blind-75 problem from memory.
Your edge: you have 8 years of real building + strong system design and concepts (see the other pages). Coding is the one muscle to build — and you have runway. Grind the patterns, practice out loud, and you'll get there.

Start today: Week 1, Problem 1 = Two Sum. Attempt it cold for 20 minutes before looking at anything.
